# Data

## Source

- Kaggle competition: [Rossmann Store Sales](https://www.kaggle.com/competitions/rossmann-store-sales)

This folder is not tracked in git (see `.gitignore`); place the raw CSV files here before running
`src/train.py` or `src/predict.py`.

## Files

- `train.csv` - historical sales data including the `Sales` column (target).
- `test.csv` - historical data excluding `Sales` (to be predicted).
- `store.csv` - supplemental store metadata.
- `sample_submission.csv` - a sample submission file in the correct format.
- `feature_importance.csv` - generated by `src/train.py` after training.
- `submission.csv` - generated by `src/predict.py`, ready for Kaggle upload.

## Data fields

- `Store` - unique Id for each store.
- `Sales` - turnover for a given day (target variable).
- `Customers` - number of customers on a given day. **Not used as a model feature** because it is
  unavailable in `test.csv` and would have to be predicted itself; including it caused an earlier,
  overly optimistic baseline.
- `Open` - 0 = closed, 1 = open.
- `StateHoliday` - state holiday indicator: `a` = public holiday, `b` = Easter, `c` = Christmas,
  `0` = none.
- `SchoolHoliday` - whether public schools were closed.
- `StoreType` - store model: `a`, `b`, `c`, `d`.
- `Assortment` - assortment level: `a` = basic, `b` = extra, `c` = extended.
- `CompetitionDistance` - distance in meters to the nearest competitor store.
- `CompetitionOpenSince[Month/Year]` - approximate opening time of the nearest competitor.
- `Promo` - whether a store is running a promo on a given day.
- `Promo2` - continuing promotion: 0 = not participating, 1 = participating.
- `Promo2Since[Year/Week]` - year/week when the store started Promo2.
- `PromoInterval` - months when a new Promo2 cycle starts (e.g. "Feb,May,Aug,Nov").

## How to download

1. Create a Kaggle account and accept the competition rules.
2. Use the Kaggle CLI:

```bash
kaggle competitions download -c rossmann-store-sales -p data/
```

3. Unzip the archive inside this folder.

## Submission format

```text
Id,Sales
1,0
2,0
3,0
...
```

Rows for days/stores with zero true sales are ignored during scoring.
